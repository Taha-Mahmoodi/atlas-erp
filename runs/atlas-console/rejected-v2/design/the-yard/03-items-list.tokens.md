# the yard: Surface 3 of 7 — Items List — composition tokens

Same composition serves both `03-items-list-light.md` and `03-items-list-dark.md` — only
color retunes between them, per `DIRECTION.md` §6's "one design in two palettes" rule.

- **Composition anchor:** `dense-grid`
- **Background mode:** `flat-surface`

**Why these two, and why they are correct here rather than manufactured variety:** this
screen's whole job is proving the direction's density claim, so the 38-row table has to
occupy the majority of the canvas with rail and chrome genuinely subordinate to it — that's
`dense-grid` by the menu's own definition ("the working table, grid, or list takes the
majority; chrome subordinate"), not a stylistic pick among several plausible options. The
table sits on one solid substrate inside one flat white/dark card, no image, no gradient
field, no texture — `flat-surface`, for the same reason: a dense data table earns nothing
from a background treatment competing with it for attention.

Per this surface's dispatch: surfaces 04 (vendor bill detail) and 05 (new item form) are
also dense/flat neighbors in this set, and the tool-shaped anti-repeat criteria are
explicitly suspended for this run — a set where three consecutive tool screens honestly land
on `dense-grid`/`flat-surface` has told the conductor something true about the surface class,
not manufactured sameness. No token was nudged toward variety it didn't earn; surface 01
(login, `centered-statement`) and surface 05 (`stacked-center`, per its own sidecar) already
carry the set's real compositional range.
