# the yard: Surface 1 of 7 — Login — composition tokens

Same composition serves both `01-login-light.md` and `01-login-dark.md` — only color retunes
between them, per `DIRECTION.md` §6's "one design in two palettes" rule.

- **Composition anchor:** `centered-statement`
- **Background mode:** `flat-surface`

**Why these two, and why they differ from the surfaces that follow:** the login card is a single
bordered, shadowed block sitting alone on an open substrate — one block on the axis, everything
else (brand mark, footer line) subordinate to it, which is `centered-statement` rather than
`stacked-center` (that token reads as a bare vertical run with no container edge; this screen has
one). The substrate behind it is one flat solid fill with the card as the only asset inline on it
— no image, no gradient field, no texture — which is `flat-surface`. Surfaces 02–07 in this set
are bento lanes and dense grids (`dense-grid`); this is deliberately the one open, calm surface in
the seven, and both tokens are chosen to read as visibly different from the dense-grid screens
that dominate the rest of the set, per the brief's instruction that this screen be distinct from
its neighbors.
